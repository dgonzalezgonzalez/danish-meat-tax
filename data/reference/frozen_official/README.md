# Frozen official source inputs

The [versioned official-input deposit](https://github.com/dgonzalezgonzalez/danish-meat-tax/releases/tag/official-inputs-2026-09-30) contains six byte-for-byte official-source snapshots used for the paper's national CPI, country beef-and-veal HICP, and bovine-slaughter analyses. The [ZIP](https://github.com/dgonzalezgonzalez/danish-meat-tax/releases/download/official-inputs-2026-09-30/official_inputs_20260930.zip) is 739,186 bytes, SHA-256 `fa07cff8d1de661fc32975f134d3173a0efd2e31757683160cb328ba7fe7df7b`. Its access path and checksum are committed in `archive_manifest.json`; each member's original size and hash remain fixed in [`replication_input_manifest.json`](../replication_input_manifest.json). The raw files are excluded from Git, following repository policy.

`scripts/replicate_official.py` downloads the deposit only when a local archived member is missing, verifies the ZIP and every member before caching it here, restores only missing `data/raw/` files, then verifies the working inputs before preprocessing and Stata estimation. A complete local cache supports offline reruns. Existing mismatched files are never overwritten silently. ZIP timestamps record packaging, not original source retrieval. No long-term preservation guarantee beyond this versioned GitHub access path is asserted.

Statistics Denmark supplied the PRIS01 and ANI41 CSVs and their metadata. Its [StatBank API page](https://www.dst.dk/en/Statistik/hjaelp-til-statistikbanken/api) states that published StatBank data may be used under Creative Commons Attribution 4.0. Eurostat supplied the beef-and-veal HICP and bovine-slaughter JSON-stat payloads. Its [copyright and reuse notice](https://ec.europa.eu/eurostat/help/copyright-notice) authorizes reuse of statistical data and metadata with source acknowledgement, subject to any individual notice. The sources, queries, and retrieval information available for each snapshot are in the root README and manifest. This repository attributes those providers and does not claim ownership of their data or extend a new license over them.

The archive contains no grocery history, Commission trade extract, PRIS04 calibration input, or Stata software package. Those ancillary stages have separate access and version requirements. The official target reproduces the core official price and production analyses from this preserved source snapshot when the documented Stata environment is available.
